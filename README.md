# Vibeweb

Vibeweb is a modern, lightweight, and natural drag-and-drop website builder. It allows you to create stunning, minimalist, and responsive websites effortlessly—without writing a single line of code.

## 🌟 Features

- **No Code Required:** Build complex layouts, add images, text, videos, and dynamic components just by dragging and dropping.
- **Pure Vanilla Output:** The websites you build export as a single, clean HTML file with embedded CSS and JavaScript. No bulky frameworks, no external dependencies.
- **8-Way Resizing:** Fully dynamic resizing of elements from all 8 corners and edges for maximum flexibility.
- **Dark & Light Mode:** Built-in multi-theme support. Toggle effortlessly between beautiful dark and light aesthetics.
- **Multi-Language Support:** Seamlessly add and manage content for multiple languages (e.g., EN, TR, AZ) in a single page.
- **Global & Local Styling:** Change the background of the entire page with one click, or customize individual blocks (Nav, Hero, Footer, etc.) to your liking.

## 🚀 Getting Started

1. Clone this repository or download the source code.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Start building! Drag elements from the left panel onto the canvas.
4. When finished, click **Export HTML** to download your complete, production-ready website file.

## 🛠 Tech Stack

- **HTML5:** Semantic and accessible structure.
- **CSS3:** Custom styling with CSS Variables, Flexbox, and Grid. No Tailwind or external UI libraries.
- **JavaScript (ES6):** State management, drag-and-drop logic, and export engine built entirely in Vanilla JS.
